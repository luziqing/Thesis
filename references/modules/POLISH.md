# Polish Module Reference — 忠于原意的语言润色

Purpose: 对已有中文学位论文正文做语言润色——语法、流畅、语气校准、按节惯例、学术表达、中译英（英文摘要）。

> 🔴 **唯一真源**：一切改写服从 `SKILL.md §Chinese Writing Boundaries`。脚本命中 ≠ 改写判据。
> 与 `deai` 分工：`deai` = 诊断并削减 AI 痕迹；`polish` = 通用语言润色。二者共用禁改清单与证据纪律。

## 核心规则

1. **忠于原意**：纯语言修改可自由做；可能触及含义的修改要么不做，要么标出请确认（before/after + 理由 + 风险）。不加强/削弱结论，不把相关写成因果，不丢限定语。
2. **禁止编造**：不加数据、公式、实验结果、引用、方法名、机理解释；缺证据处留括注请作者补，不自己填。
3. **默认保守**：小改优于大改，不改优于小改；需要结构重写时停下让作者选「轻润色 / 深度重写」。
4. **语气校准**：动词阶梯 证明/证实 > 表明/验证 > 提示/可能，**只允许下调**；带数字/p 值的「显著」有证据不删；`首次/唯一/最优` 软化或标出。
5. **公平对待前人**：不削成稻草人，写精确差异。
6. **按节惯例**：绪论定位 / 方法可复现 / 结果过去时只陈述 / 讨论解释+hedging / 结论不重复摘要 / 摘要五要素 / 标题可检索——见 `POLISH_GUIDE.md` §4。
7. **去 AI 腔**：命中清单见 `DEAI_GUIDE.md`，命中≠必删；剥净后保持精确与诚实，不死气沉沉。
8. **中译英**：先提含义再写句，补回隐含逻辑，术语稳定，修中式英语，翻译时不拔高。

## 交付（固定三块）

`检查结果` / `改写稿` / `改动说明（含未改及原因）`
- 文件内草稿：直接改文件，用 diff 作精确记录；对话内文本：给完整润色稿。
- 长文档分块标注「第 i 部分，共 N 部分」，每块完整可用。
- 不可读元素（图片公式等）：指出位置请人工核对，不猜内容。

## 何时无法润色

逻辑链断裂 → 建议先重写该节；核心论断被自报数据证伪 → 不写防御、不编乐观解读，转 `topic`/`review` 核查。
